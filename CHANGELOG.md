# Changelog

## 0.3.0 — 2026-09-23

- Prepared the package for npm publication as `vibe-coding-sdd`.
- Added npm-safe package metadata, public publish configuration, and pre-publish tests.
- Added GitHub Actions publishing workflow for npm Trusted Publishing (OIDC).
- Added release documentation for the one-time first publish and future automated releases.
- Documented the short npm install command: `npx vibe-coding-sdd init`.

## 0.2.0 — 2026-09-23

- Added one-command installer runnable directly from GitHub with `npx`.
- Added interactive and non-interactive installation for Antigravity, Claude Code, Codex, Kiro, and Generic environments.
- Added project/global scopes, English/Chinese rule selection, dry-run, safe conflict handling, backups, and doctor command.
- Added Chinese versions of the bootstrap prompt and core methodology.
- Expanded English and Simplified Chinese READMEs and installation guides.

## 0.1.0 — 2026-09-23

- Initial public methodology.
- Added Small Change, Feature, and Bug lanes.
- Added reusable Feature, Bugfix, Small Change, Code Review, and Browser QA skills.
- Added universal bootstrap prompt and project/spec templates.
- Added initial Antigravity, Claude Code, Codex, and Kiro adapter notes.
