# Kiro Adapter

Kiro's specification-oriented workflow maps naturally to this repository.

Recommended mapping:

- Use the project's persistent Kiro guidance/steering mechanism for `core/GLOBAL_RULES.md` and project constraints.
- Map Feature work to requirements/specification, design, and tasks artifacts.
- Preserve Vibe Coding SDD's extra gates: explicit task classification, proportional process, skeptical review, browser/user verification, and final convergence.
- Store project truth in `docs/` and current change truth in `specs/` or Kiro's native spec structure.

Use `UNIVERSAL_BOOTSTRAP_PROMPT.md` to let the installed Kiro version choose current native paths and formats.
